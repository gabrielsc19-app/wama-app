Instalación:
1. Descomprimir el ZIP.
2. Copiar su contenido sobre C:\Users\gabri\wama-app y aceptar reemplazos.
3. Ejecutar npm run dev.
4. Abrir http://localhost:3000/modulos/expense-hub
5. Abrir http://localhost:3000/expense-hub

Nota de validación:
La entrega se preparó sobre el proyecto enviado. No fue posible ejecutar npm install/build dentro del entorno de generación por disponibilidad de dependencias, por lo que la validación final debe realizarse localmente con npm run build.
